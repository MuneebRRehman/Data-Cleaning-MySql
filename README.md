# MySQL Data Cleaning Project

## Overview
This project demonstrates **data cleaning using MySQL**.  
It is part of my learning journey from the **Analytics Bootcamp by Alex The Analyst**.

The goal of this project is to:
- Identify and remove duplicates
- Handle missing and inconsistent values
- Standardize and clean text columns
- Prepare datasets for further analysis

## Files in this repository
- `data_cleaning_project.sql` : Full SQL script with comments  
- `layoffs_sample.csv` (optional) : Sample dataset for demonstration  
- `cleaned_data_sample.csv` (optional) : Sample of cleaned data  
- `images/` (optional) : Screenshots of key SQL queries

## Key Techniques
- Common Table Expressions (CTEs) to handle duplicates
- Window functions (`ROW_NUMBER()`) for duplicate detection
- Self-joins to fill missing values
- Data standardization and trimming
- Handling NULL values

## How to use
1. Load the sample dataset (`layoffs_sample.csv`) into your MySQL database.
2. Run the `data_cleaning_project.sql` script step by step.
3. Review the results in your database.

## Skills Practiced
- SQL fundamentals (SELECT, JOINs, UPDATE)
- Data cleaning and preparation
- CTEs and window functions
- Problem-solving with real-world datasets
